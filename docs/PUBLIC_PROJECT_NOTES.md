# Public Project Notes

Glassline is public from the start. Keep the repo clean:

- Do not commit Epic Engine binaries or third-party renderer binaries.
- Do not commit private StreetSim assets.
- Keep examples generic.
- Use MIT-compatible code only unless a dependency is isolated and documented.
- Keep renderer backends behind interfaces so commercial or platform-specific backends can live outside the core repo.
- Prefer small, reviewable milestones over a giant engine fork.
