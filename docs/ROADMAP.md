# Roadmap

## Milestone 0: Public Scaffold

- Runtime bridge package
- Unreal plugin shell
- Racing HUD example
- Documentation for renderer/input/message architecture

## Milestone 1: Prototype Unreal Layer

- Spawn a transparent browser-backed layer
- Load local `glassline://` content
- Send Unreal JSON events into JavaScript
- Receive JavaScript commands in Unreal
- Hot reload local UI files

## Milestone 2: Real Renderer

- CEF offscreen renderer prototype
- Render to texture
- alpha compositing
- input coordinate mapping
- renderer process lifecycle

## Milestone 3: Game UI Ergonomics

- gamepad navigation
- modal/layer stack
- focus rules
- route transitions
- profiler overlay
- packaging manifest

## Milestone 4: Production Features

- texture atlas/caching strategy
- font packaging
- video/audio policy
- crash reporting hooks
- automated screenshot tests
- Unreal sample project
